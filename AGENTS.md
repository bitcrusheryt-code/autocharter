# Human-Directed Design Guidelines

## Purpose

Create interfaces that feel intentionally designed by a person, not generated from generic AI web-design patterns.

The goal is not to make the website look old or imperfect. The goal is to make it feel **specific, purposeful, restrained, and appropriate for the actual project**.

## Core Principle

**Do not add design elements merely because they are common in AI-generated websites.**

If the user asks for a minimal page, keep it genuinely minimal. Do not expand the design without permission.

A simple page is not incomplete just because it has fewer elements.

## Avoid Generic AI Design

* Do not automatically use purple/blue gradients.
* Do not use excessive rounded cards.
* Do not use glassmorphism unless explicitly requested.
* Do not add unnecessary shadows, floating blobs, glowing effects, or animated backgrounds.
* Do not create a generic SaaS landing page layout.
* Do not add sections, buttons, statistics, testimonials, or features that were not requested.
* Do not add decorative elements just to fill empty space.
* Do not use excessive animations.
* Do not make every element look like a reusable template card.
* Do not force perfect symmetry when it does not serve a purpose.
* Do not add trendy UI patterns simply because they are popular in AI-generated designs.

## Respect the Requested Scope

* Follow the user's requested layout literally.
* Do not interpret "make a simple page" as "make a complete modern landing page."
* Do not add extra navigation, dashboards, sections, or components without permission.
* Do not replace a deliberately empty or spacious layout with a busier one.
* Do not introduce new visual concepts that were not part of the request.
* If something is not required, do not add it automatically.

## Prioritize Intentionality

* Every UI element must serve a clear purpose.
* Prefer simple layouts over impressive-looking layouts.
* Use the user's actual content instead of filler copy.
* Make the design fit the project's identity, not current AI trends.
* Preserve unusual but intentional design decisions.
* Do not redesign existing work unnecessarily.
* Do not "improve" something by making it more complicated.

## Visual Style

* Prefer restrained, coherent colors.
* Avoid neon colors unless explicitly requested.
* Use typography with a clear hierarchy.
* Use spacing naturally, not mechanically.
* Avoid excessive rounded corners.
* Avoid making every section look like a floating panel.
* Avoid unnecessary gradients and decorative effects.
* Use visual hierarchy through placement, typography, and spacing—not constant effects.

## Content

* Never invent marketing copy.
* Never add generic promotional text unless requested.
* Avoid phrases such as:
  * "Unleash your potential"
  * "The future of innovation"
  * "Seamless experience"
  * "Powerful solutions"
  * "Built for the future"
  * "Revolutionizing the way..."
* Write direct, specific, human-sounding text.
* Do not make a personal project sound like a corporate startup unless explicitly requested.

## Personal Websites and Small Projects

For personal websites, portfolios, project pages, and small independent projects:

* Prefer authenticity over marketing polish.
* Avoid startup-style hero sections.
* Avoid unnecessary feature grids.
* Avoid fake testimonials or invented statistics.
* Avoid excessive calls to action.
* Let the actual projects and information be the focus.
* A quiet, simple page is acceptable.
* Do not make the website look like a commercial template unless requested.

## Do Not Over-Engineer the Design

* Do not add components only because they are available in the UI library.
* Do not add unnecessary responsive behavior that changes the intended layout.
* Do not add complex interactions to simple pages.
* Do not add loading screens, animated transitions, or decorative hover effects unless they have a clear purpose.
* Do not create unnecessary abstraction in the visual structure.
* Do not turn a simple page into a full application without explicit instruction.

## Before Adding Anything

Before adding a new section, component, animation, effect, or visual element, ask:

1. Did the user explicitly request this?
2. Does it serve a real purpose?
3. Does it fit the project's identity?
4. Would the page still be better without it?

If the answer is unclear, do not add it.

## Final Design Check

Before finishing, evaluate the result:

> "Would this look like a real person's personal project, or like an AI-generated landing page template?"

If it looks generic, simplify it.

If it looks over-designed, remove unnecessary elements.

If it looks like every other AI-generated website, make more deliberate and project-specific decisions.

## Important Rule

**Do not confuse "modern" with "AI-generated."**

A modern interface can still be simple, personal, restrained, and human-directed.

The objective is not to avoid all modern design. The objective is to avoid generic, automatic, unnecessary design decisions.
